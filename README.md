UNO Terminal - это терминальная версия немало известной и всеми любимой карточной игры UNO! В ней я реализовал все правила и возможности игры, а так же сделал 2
режима: UNO Classic и UNO Flip. В игре есть общая статистика партий и подробная статистика последниих 20.  Все правила и навигация есть в разделе "правила" 
в главном меню игры. Чтобы выбирать пункты в меню введите их номер и нажмите enter.

Используемые библиотеки:

random - для раздачи карт

datetime - для считывания времени начала и конца партии, вычисления её длительности и сохранения этих данных в подробную статистику

json - для работы с json файлами и возможности сохранять статистику после выхода из игры
